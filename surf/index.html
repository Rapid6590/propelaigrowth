SURF™ 四步（全天班下午：用你們自己的東西走一遍）

  1. Set 定行為目標

    先定客戶要做的那一個看得見的動作，再問他要想什麼、感覺什麼。

  2. Uncover 找出障礙

    四種障礙裡，是哪一種擋住了他。

  3. Remove 拆掉障礙

    改報價單怎麼排、第一句話講什麼。

  4. Focus 放大動機

    五種動機裡，挑對的那一種放大。

改一版長什麼樣（示意：提案第一頁，全天班）改前 第一頁「公司簡介與得獎紀錄」→ 改後 第一頁「您上次提到的三個問題，我們各給一個做法」：先回應「這對我有用嗎」的疑問
